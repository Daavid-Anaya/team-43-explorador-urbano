# Kiro Steering

Los colaboradores que usen Amazon/AWS Kiro leen `.kiro/steering/steering.md` para orientarse antes de abrir issues, crear ramas o implementar slices del MVP.

La fuente de verdad (alcance, requisitos, specs, decisiones técnicas y tareas) vive en `openspec/changes/urban-explorer-mvp/`. Kiro es una herramienta de apoyo: no se crea `.kiro/specs/` para evitar duplicar y desincronizar especificaciones.
